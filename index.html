FOUNDATION

Engineering

The degree is the foundation. Your goal is to become exceptionally good at learning difficult technical concepts and turning them into working systems.

Engineering Development Phases

Phase 1 — Academic Foundation

Build the fundamentals.

  • Calculus
  • Linear algebra
  • Differential equations
  • Physics
  • Engineering mechanics
  • Probability and statistics

Output: strong grades + organized notes + solved problem sets + understanding rather than memorization.

Phase 2 — Computing Foundation

Become technically fluent.

  • Programming fundamentals
  • Data structures
  • Git
  • Linux
  • Debugging
  • Command line

Output: multiple small programs and at least one meaningful engineering project.

Phase 3 — Systems Thinking

Understand how components interact.

  • Computer architecture
  • Operating systems
  • Networking
  • Databases
  • APIs
  • Embedded systems
Phase 4 — Engineering Depth

Choose technical areas worth going deep on.

  • Cybersecurity
  • AI engineering
  • Embedded systems
  • Semiconductor design
  • Software systems
PROJECT-DRIVEN PROGRAMMING

Programming + Projects

Do not learn programming languages just to collect languages. Every language has a purpose. Progress through phases: syntax → fundamentals → systems → projects → real-world application.

🐍 Python

Automation, AI, data, backend and business tools.

Phase 1 — Python Fundamentals

Learn to think programmatically.

  • Variables
  • Conditionals
  • Loops
  • Functions
  • Lists / dictionaries / sets
  • File handling
  • Exceptions
  • Modules
BEGINNER

Project 1 — CLI Expense Tracker

Build a command-line application that lets a user add expenses, categorize them, search them and calculate totals.

Stretch: save data to JSON or CSV.

BEGINNER+

Project 2 — Engineering Unit Converter

Create a tool that converts engineering units such as temperature, pressure, length, energy and power.

Phase 2 — Practical Python

Build useful automation.

  • APIs
  • HTTP requests
  • JSON
  • Web scraping concepts
  • Regular expressions
  • Automation
  • Databases
INTERMEDIATE

Project 3 — Job Application Tracker

Create a local application that tracks companies, applications, deadlines, interviews and follow-ups.

INTERMEDIATE

Project 4 — API Data Dashboard

Connect to a public API, retrieve data, clean it and display useful statistics.

Phase 3 — Engineering Python

Use Python to solve technical problems.

INTERMEDIATE+

Project 5 — Engineering Simulation Tool

Create a simulation involving physical or engineering variables. Allow users to change parameters and visualize the output.

ADVANCED

Project 6 — Automated Engineering Report Generator

Input measurements or simulation results and automatically generate charts, statistics and a formatted engineering report.

Phase 4 — AI + Python

Combine programming with modern AI.

ADVANCED

Project 7 — AI Engineering Assistant

Build a tool that can ingest technical documents and help retrieve, summarize and organize engineering information.

ADVANCED

Project 8 — AI Business Automation

Build an automated workflow that receives a business input, processes it with AI and produces a useful output.

ONE ACTIVE BUSINESS

Business Lab

Your objective during university is not to prove you can build a billion-dollar company immediately. It is to accumulate founder reps.

🚦 Business Validation Gates

Gate 1

10 customer conversations.

Gate 2

Confirm painful repeated problem.

Gate 3

Deliver manually.

Gate 4

Get first dollar.

Gate 5

Reach five paying customers.

Gate 6

Find repeatable acquisition.

Gate 7

Scale, pivot or kill.

Founder Rules

Sell before scaling

Manually deliver the result before spending months building software.

Market > Idea

Look for existing spending, painful problems and reachable customers.

One offer

One customer, one problem, one offer before expanding.

Proof > Complexity

Five paying customers beats an impressive product with zero users.

FAIL CHEAPLY

Experiment Lab

Treat businesses as experiments. Your goal is to develop judgment, not protect an idea.

Experiment



Experiment Philosophy

  • Small test before large build.
  • Evidence before opinion.
  • Revenue is stronger evidence than compliments.
  • Rejection is information.
  • Kill weak ideas quickly.
  • Double down on demonstrated demand.
AI-NATIVE ENGINEER

AI Leverage

The goal is not to chase every new AI product. The goal is to become an engineer who can use AI and automation to dramatically increase output.

Phase 1 — AI-Assisted Work
  • AI coding assistants
  • Prompting
  • Debugging
  • Code review
  • Research
  • Documentation
Phase 2 — Automation
  • APIs
  • Webhooks
  • Workflow automation
  • Data pipelines
  • Browser automation
  • Agents

Project — Automated Business Workflow

Take a repetitive business process and automate as much of it as possible. Measure time saved.

Phase 3 — AI Engineering
  • LLM APIs
  • RAG
  • Embeddings
  • Vector databases
  • Evaluation
  • Agent architecture

Project — Engineering Knowledge Assistant

Build a system that can retrieve information from a technical knowledge base and provide grounded answers.

Phase 4 — AI + Business

Project — AI-Powered Internal Tool

Build a real tool that eliminates a repetitive business process. Ideally use it in your own business.

TECHNICAL OPTIONALITY

Cybersecurity

Cybersecurity is a specialization and future optionality. It is not automatically the business you need to build today.

Phase 1 — Years 1–2 — Foundation
  • Linux
  • Networking
  • Python
  • Git
  • Operating systems
  • Security fundamentals

Project — Secure Linux Server Lab

Create a Linux environment, configure services, users and permissions, then document how you hardened it.

Phase 2 — Years 2–3 — Security Engineering
  • Authentication
  • Web security
  • Cloud security
  • Secure software
  • Threat modeling
  • Logging

Project — Security Assessment Lab

Build a deliberately vulnerable educational application, identify weaknesses and then fix them.

Phase 3 — Years 3–4 — Specialize

Choose one major area rather than attempting to master everything.

  • Cloud security
  • Application security
  • Offensive security
  • Security engineering
  • Embedded / IoT security
PARKED — LONG-TERM BET

Semiconductors

Keep the deep-tech ambition alive without allowing it to compete with your first business and engineering foundation.

01 — Electrical Fundamentals

Circuits, electronics, signals and basic semiconductor concepts.

02 — Digital Logic

Boolean logic, combinational logic, sequential logic and FSMs.

03 — Computer Architecture

Processors, memory, instruction sets and hardware/software interaction.

04 — Verilog / SystemVerilog

Describe and simulate digital hardware.

05 — FPGA

Implement real hardware systems and accelerators.

06 — ASIC Design

Learn professional chip design concepts and flows.

07 — Physical Design

Synthesis, timing, place and route.

08 — Tapeout

Long-term objective. Not a Year 1 requirement.

CREDENTIALS

Certifications

Certifications support the roadmap. They do not define the roadmap.

Decision rule: Do not ask "What certification can I get?" Ask: "What opportunity makes this certification worth my time?"
Year 1

Minimal credentialing

Focus primarily on engineering and projects. Only pursue a foundational certification if it supports a specific goal.

Year 2

Cybersecurity credential

If cybersecurity is becoming a serious specialization, a foundational security certification can make sense.

Year 3

Specialization credential

Only pursue cloud/security credentials if an internship, job or specialization makes them valuable.

Year 4

Stop collecting

Prioritize technical proof, internships, research, engineering work and business results.

NORTH STAR

Four-Year Plan

Each year has a dominant objective. The goal is not to master everything simultaneously. The goal is to compound.

YEAR 1 — FOUNDATION + FIRST BUSINESS

Become competent and get your first real market feedback.

🎓 Engineering

  • Build strong academic habits.
  • Learn calculus, physics and engineering fundamentals.
  • Learn programming fundamentals.
  • Learn Git and basic Linux.
  • Build your first engineering projects.

💻 Programming

  • Python fundamentals
  • C fundamentals
  • HTML/CSS/JavaScript basics
  • SQL fundamentals

🚀 Business

  • Talk to potential customers.
  • Complete at least 20 customer conversations per quarter.
  • Identify painful recurring problems.
  • Run small experiments.
  • Attempt to get the first dollar.

🤖 AI

  • AI-assisted coding
  • AI research
  • Prompting
  • Basic automation
  • APIs

🔐 Cybersecurity

  • Linux
  • Networking basics
  • Security fundamentals
  • Basic security labs

⚡ Semiconductors

  • Keep the track parked.
  • Study digital logic only if academic workload allows.

📜 Certifications

No certification collecting. Only pursue one if it has a clear purpose.

🏆 Proof of Work

  • 3–5 meaningful programming projects.
  • At least one engineering project.
  • Business experiment documentation.
  • GitHub portfolio.
Year 1 win: You do not need a successful startup. You need: technical foundations + first customers + first serious projects + better judgment.
YEAR 2 — REPEATABILITY

Become more technically capable and determine whether the business deserves more attention.

🎓 Engineering

  • More advanced engineering coursework.
  • Systems thinking.
  • Data structures.
  • Computer architecture.
  • Operating systems.

💻 Programming

  • Intermediate Python
  • C/C++ systems programming
  • JavaScript/TypeScript applications
  • SQL/database systems

🚀 Business

  • Try to reach multiple paying customers.
  • Measure retention.
  • Improve the offer.
  • Automate repetitive business tasks.
  • Decide whether to scale, pivot or kill.

🤖 AI

  • Workflow automation.
  • LLM APIs.
  • RAG fundamentals.
  • AI-powered internal tools.

🔐 Cybersecurity

  • Networking deeper.
  • Web security.
  • Authentication.
  • Security engineering.
  • Security projects.

⚡ Semiconductors

  • Digital logic.
  • Computer architecture.
  • Optional Verilog introduction.

📜 Certifications

Consider a foundational security certification if cybersecurity has become a serious specialization.

🏆 Proof

  • More advanced software project.
  • Cybersecurity lab.
  • Business case study.
  • Technical portfolio improvement.
Year 2 win: You can build real systems, understand technical fundamentals, and have evidence that people will pay for something you provide.
YEAR 3 — LEVERAGE + SPECIALIZATION

Choose where your technical depth becomes valuable.

🎓 Engineering

  • Advanced technical courses.
  • Internship or research.
  • Specialized engineering knowledge.
  • Major technical project.

💻 Programming

  • Advanced systems programming.
  • Full-stack systems.
  • Performance optimization.
  • Hardware/software integration.

🚀 Business

  • Scale if there is evidence.
  • Otherwise kill or pivot.
  • Develop repeatable acquisition.
  • Automate operations.
  • Improve economics.

🤖 AI

  • Agent systems.
  • Evaluation.
  • Production AI systems.
  • AI automation inside the business.

🔐 Cybersecurity

Choose ONE:

  • Cloud security
  • Application security
  • Offensive security
  • Security engineering
  • Embedded security

⚡ Semiconductors

  • Verilog/SystemVerilog.
  • FPGA projects.
  • Digital design.
  • Hardware acceleration.

📜 Certifications

Only pursue specialization certifications if they support an internship, job or clearly defined technical objective.

🏆 Proof

  • Internship experience.
  • Major engineering project.
  • Cybersecurity specialization project.
  • FPGA/hardware project if pursuing chips.
  • Business results.
Year 3 win: You are no longer simply "learning engineering." You have a recognizable technical direction and real evidence.
YEAR 4 — LAUNCH

Graduate with leverage rather than simply a degree.

🎓 Engineering

  • Finish degree strongly.
  • Complete capstone.
  • Develop professional engineering communication.
  • Prepare for industry.

💻 Programming

  • Use whichever languages are relevant to your specialization.
  • Focus on architecture and production-quality systems.
  • Build one exceptional portfolio project rather than ten mediocre ones.

🚀 Business

  • Continue a proven business.
  • Or launch a better second experiment using accumulated judgment.
  • Determine whether it can continue after graduation.

🤖 AI

  • Use AI as a force multiplier across engineering and business.
  • Build production-grade AI systems where useful.

🔐 Cybersecurity

  • Deepen your chosen specialization.
  • Prepare for professional security roles if desired.
  • Build serious security proof.

⚡ Semiconductors

  • FPGA/ASIC design.
  • Hardware architecture.
  • Potential tapeout path if this becomes the primary deep-tech direction.

📜 Certifications

No certification collecting. Prioritize: experience + portfolio + references + technical ability.

🏆 Proof

  • Strong engineering portfolio.
  • Internship/work experience.
  • Major technical project.
  • Business results.
  • Cybersecurity specialization proof.
  • Potential hardware project.
Year 4 win: Graduate with:

Engineering degree + Technical portfolio + Industry experience + AI leverage + Founder judgment + Cybersecurity optionality + Long-term semiconductor path
The sequencing matters. You are NOT trying to become:

Engineer + cybersecurity expert + semiconductor engineer + AI researcher + CEO simultaneously.

You are building them in layers. Foundation → Business reps → Technical depth → Leverage → Specialization.
